# HOSQ / Glaze / yyjson 再測定 — 2026-09-08

FastReaderの未知スカラーメンバーskipと、コンテナの閉じ括弧をローカルに保持する変更を含む現行版で測定した。ライブラリ本体はこの測定では変更していない。

Compact 12ケース、Pretty 3ケース。三者とも同じAC電源環境で新たに測定し、過去の時間を流用していない。Clang21 -O3、Glaze8.3.0、yyjson0.12.0。HOSQ Auto・bounded入力・paddingなし。順序を変えた2巡、各5反復、反復最低0.1秒。ビルドと描画は測定と並行していない。

Glazeは型付きスキーマで必要なフィールドだけ取得し、不要項目をskipする。partial_read=falseで全文書を処理。yyjsonはDOM生成・取得・破棄を含む。HOSQの全項目取得は宣言順のEntryスキーマを使用する。検証保証などの差は[既存の比較契約](benchmark-auto-threeway.md)のまま。

グラフは各巡のyyjsonのCPU時間を1とする比の平均。短いほど速い。ひげは2巡の範囲であり、信頼区間ではない。大サイズ全項目取得のHOSQでは2巡で約6%の差があり、微小な性能差を断定しない。
